# Finance Bot

Telegram-бот для учёта личных финансов. Пишешь «кофе 50», выбираешь расход или доход и категорию, а бот записывает транзакцию и пересчитывает баланс счёта.

## Возможности

- Несколько счетов: 💳 карта, 💵 наличные, 🪙 криптовалюта
- Валюты: USD, EUR, RUB, BYN
- Быстрая запись одним сообщением: `кофе 50` или `кофе 50,5`
- Учёт расходов и доходов
- Готовые категории и свои категории с эмодзи
- Проверка введённой суммы: запятая, ноль, отрицательные и слишком большие числа
- Баланс обновляется на стороне базы данных (`balance = balance + ...`), поэтому одновременные операции не теряются
- Защита от устаревших кнопок в чате

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Регистрация, создание первого счёта |
| `/add_category` | Добавить свою категорию |
| `описание сумма` | Записать трату или доход, например `такси 12,5` |

## Стек

- Python (разработка велась на 3.14)
- [aiogram](https://docs.aiogram.dev/) 3 — Telegram-бот
- SQLAlchemy 2 (async) + asyncpg — работа с базой
- PostgreSQL в Docker
- Alembic — миграции
- python-dotenv — переменные окружения

## Запуск

1. Клонируй репозиторий и перейди в папку проекта:
   ```
   git clone <адрес-репозитория>
   cd finance-app
   ```

2. Создай виртуальное окружение и установи зависимости:
   ```
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
   В Linux и macOS активация: `source venv/bin/activate`.

3. Создай файл `.env` по образцу `.env.example` и заполни его:
   ```
   BOT_TOKEN=токен_от_BotFather
   DB_PASSWORD=придуманный_пароль_для_базы
   ```

4. Запусти базу данных:
   ```
   docker compose up -d
   ```

5. Примени миграции:
   ```
   alembic upgrade head
   ```

6. Заполни стандартные категории:
   ```
   python -m scripts.seed_categories
   ```

7. Запусти бота:
   ```
   python -m app.bot.main
   ```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота, который выдаёт [@BotFather](https://t.me/BotFather) |
| `DB_PASSWORD` | Пароль пользователя `postgres` в базе данных |

## Структура проекта

```
finance-app/
├── alembic/              миграции базы данных
├── app/
│   ├── bot/
│   │   ├── handlers/     обработчики: start, transaction, add_category
│   │   ├── states.py     состояния диалогов (FSM)
│   │   └── main.py       точка входа бота
│   ├── models/           таблицы: User, Account, Category, Transaction
│   ├── repositories/     вся работа с базой данных
│   ├── constants.py      валюты и типы счетов
│   ├── database.py       подключение к PostgreSQL
│   └── parsing.py        разбор и проверка введённой суммы
├── scripts/
│   └── seed_categories.py   стартовые категории
├── docker-compose.yml    PostgreSQL
└── requirements.txt
```

Проект разделён на слои: обработчики бота не пишут SQL, а обращаются к репозиториям, которые работают с моделями.
