# Finance Bot

Telegram-бот для учёта личных финансов. Пишешь «кофе 50», выбираешь тип, дату и категорию — бот записывает транзакцию и пересчитывает баланс счёта. Историю операций можно листать прямо в чате и удалять ошибочные записи.

## Возможности

- Несколько счетов: 💳 карта, 💵 наличные, 🪙 криптовалюта
- Валюты: USD, EUR, RUB, BYN
- Быстрая запись одним сообщением: `кофе 50` или `кофе 50,5`
- Учёт расходов и доходов
- Выбор даты транзакции: сегодня или вручную в формате `дд.мм.гггг`
- Готовые категории и свои категории с эмодзи
- Статистика расходов по категориям за любой месяц
- История операций с постраничным просмотром (по 10 записей) и кнопками «Назад» / «Вперёд»
- Удаление операции из истории с подтверждением; баланс счёта автоматически откатывается
- Проверка введённой суммы: запятая, ноль, отрицательные и слишком большие числа
- Баланс обновляется на стороне базы данных (`balance = balance + ...`), поэтому одновременные операции не теряются
- Операции можно просматривать и удалять только на своём счёте — чужую запись не удалить даже подменой данных кнопки
- Текст, введённый пользователем, экранируется перед выводом, поэтому символы вроде `<` и `&` не ломают сообщения
- Защита от устаревших кнопок в чате
- Отмена любого действия через `/cancel` или кнопку «Отмена»

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Регистрация, создание первого счёта |
| `/add_category` | Добавить свою категорию |
| `/history` | Последние операции с листанием и удалением |
| `/stats` | Статистика расходов за текущий месяц |
| `/stats мм.гггг` | Статистика за конкретный месяц, например `/stats 09.2026` |
| `/cancel` | Отменить текущее действие |
| `описание сумма` | Записать трату или доход, например `такси 12,5` |

### Как удалить операцию

1. Открой `/history` — у каждой записи есть номер и кнопка `🗑`.
2. Нажми `🗑` нужного номера — бот покажет операцию и спросит подтверждение.
3. «✅ Да, удалить» удаляет запись и возвращает тебя на ту же страницу истории, «Отмена» — просто возвращает.

## Стек

- Python (разработка велась на 3.14)
- [aiogram](https://docs.aiogram.dev/) 3 — Telegram-бот
- SQLAlchemy 2 (async) + asyncpg — работа с базой
- PostgreSQL в Docker
- Alembic — миграции
- FastAPI — REST API (в разработке)
- pytest + pytest-asyncio — тесты
- ruff — линтер и форматирование
- python-dotenv — переменные окружения

## Запуск

1. Клонируй репозиторий и перейди в папку проекта:
   ```
   git clone <адрес-репозитория>
   cd finance-app
   ```

2. Создай виртуальное окружение и установи зависимости:
   ```
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
   В Linux и macOS активация: `source venv/bin/activate`.

3. Создай файл `.env` по образцу `.env.example` и заполни его:
   ```
   BOT_TOKEN=токен_от_BotFather
   DB_PASSWORD=придуманный_пароль_для_базы
   ```

4. Запусти базу данных:
   ```
   docker compose up -d
   ```

5. Примени миграции:
   ```
   alembic upgrade head
   ```

6. Заполни стандартные категории:
   ```
   python -m scripts.seed_categories
   ```

7. Запусти бота:
   ```
   python -m app.bot.main
   ```

## Тесты

Тесты работают с отдельной базой `finance_test`: перед каждым тестом в ней создаются таблицы, после — всё удаляется. Рабочие данные бота не затрагиваются.

1. Установи зависимости для разработки:
   ```
   pip install -r requirements-dev.txt
   ```

2. Один раз создай тестовую базу (контейнер с PostgreSQL должен быть запущен):
   ```
   docker compose exec db psql -U postgres -c "CREATE DATABASE finance_test;"
   ```

3. Запусти тесты:
   ```
   pytest -v
   ```

Что покрыто тестами: разбор и проверка суммы, обновление баланса, удаление операций (откат баланса для расхода и дохода, запрет удаления чужой записи, несуществующий id).

Проверка стиля кода:
```
ruff check
ruff format
```

## REST API (в разработке)

Минимальный API на FastAPI для будущего Telegram Mini App: получение, создание и удаление транзакций.

```
uvicorn app.api.main:app --reload
```

Документация открывается по адресу http://127.0.0.1:8000/docs.

## Структура проекта

```
finance-app/
├── alembic/              миграции базы данных
├── app/
│   ├── api/              REST API: точка входа, роутер, Pydantic-схемы
│   ├── bot/
│   │   ├── handlers/     обработчики: start, transaction, add_category, history, stats, cancel
│   │   ├── states.py     состояния диалогов (FSM)
│   │   └── main.py       точка входа бота
│   ├── models/           таблицы: User, Account, Category, Transaction
│   ├── repositories/     вся работа с базой данных
│   ├── constants.py      валюты, типы счетов, размер страницы истории
│   ├── database.py       подключение к PostgreSQL
│   └── parsing.py        разбор и проверка введённой суммы
├── scripts/
│   └── seed_categories.py   стартовые категории
├── tests/                тесты pytest и фикстура тестовой базы (conftest.py)
├── docker-compose.yml    PostgreSQL + volume для данных
├── requirements.txt      зависимости приложения
└── requirements-dev.txt  зависимости для разработки: pytest, ruff
```

Проект разделён на слои: обработчики бота и API не пишут SQL, а обращаются к репозиториям, которые работают с моделями.
