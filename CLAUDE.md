## О проекте
Telegram-бот учёта финансов: счета, категории, операции, история, статистика. Дальше планируются переводы между счетами, REST API и Telegram Mini App.

Стек: Python, aiogram 3, SQLAlchemy 2 (async) + asyncpg, PostgreSQL в Docker, Alembic, FastAPI, pytest + pytest-asyncio, ruff.

Структура: `app/bot` (хендлеры), `app/repositories` (работа с БД), `app/models`, `app/api`, `app/constants.py`, `tests/`, `alembic/`.

## Правила проекта
- Репозитории делают только `flush`, а `commit` делает хендлер. Так операции с балансом атомарны.
- Никогда не доверяй `callback_data`: всегда проверяй владельца (счёт или пользователя).
- Пользовательский текст в HTML-сообщениях экранируй через `html.escape`.
- Любое изменение моделей идёт через Alembic. Миграцию сгенерируй и проверь глазами до `upgrade`.
- Тесты используют отдельную БД `finance_test`.

## Команды
- Запуск БД: `docker compose up -d`
- Бот: `python -m app.bot.main`
- Тесты: `pytest`
- Линтер: `ruff check --select I,F401 --fix` и `ruff format`
- Миграции: `alembic revision --autogenerate -m "..."`, затем `alembic upgrade head`
